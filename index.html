Gold Set Tool

Designing a QA workflow for AI training image sets at Block, Inc.

The Problem

A folder of photos arrives. Sorting and labelling is manual. The QA pass keeps slipping. The team maintains curated reference photo sets used to fine-tune an internal generative model. Each product line needs specific angles, finishes, and environments. Holes in the set become holes in what the model can imagine.

The first version of the tool worked but had three problems: AI sorting was painfully slow, the UX required too many clicks, and sorting accuracy was poor.

The Approach

Three jobs, in order of how much they hurt:

01

Sort the mess

Sort the messy folder into the right buckets. Raw photos arrive unsorted - the tool needs to place each one into the correct product-line category automatically.

02

Show coverage

Show coverage at a glance - which cells are empty. The team needs to see gaps in the reference set without clicking through hundreds of images.

03

Stage QA

Stage QA - let a reviewer click through and approve. Every sorted image needs a human sign-off before it enters the gold set.

How I Worked with AI

1
Squeeze the model

Rewrote the AI sorting pipeline: swapped to a smaller, cheaper vision model, reduced image resolution, switched to parallel batch processing with structured JSON output. Order-of-magnitude cost reduction while improving consistency.

2
Steal the keyboard from the AI

The model produced inconsistent labels for the same thing. Added layered normalization: deterministic key sorting first, then a hand-curated synonym table, then a drag-to-merge gesture in the UI. Each layer cheaper than the one above.

3
Hybrid sort - keyword first, AI for the ambiguous

Most files had the answer in the filename already. Regex handles those first. The vision model only sees the genuinely ambiguous ones. Reviewers only see the low-confidence cases.

4
Match the existing system

The tool sits inside a larger asset management system. Fed the existing UI to Claude alongside my design, asked for a styling diff. 14 small alignments - none visible alone, all visible together. The tool stopped looking bolted-on.

Design Decisions

The tool is a checklist, not a generator.

Surfacing gaps is its job. Filling them is a creative act that belongs to designers.

Coverage matrix over per-image badges.

Concentrating the signal in one corner lets the photos breathe everywhere else.

Keep the receipts.

Every label keeps its source - AI-given, filename-derived, manually overridden. Provenance is what makes an AI tool trustworthy.

Reflection

Cap what AI does. The human stays in charge.

The model labels, canonical keys deduplicate, and the matrix highlights gaps, but a person always makes the final call. Each layer is cheaper to run than the one above, and easier to verify.
